# 代码反述 Prompt：双翻译

来源：《驾驭AI编程》第5章5.7节。第一遍把需求变成代码，第二遍把代码反述为自然语言，再由人核对两份描述的差异。它与[独立生成测试](qa-independent-test.md)是不同的验证动作。

## 第一阶段：只反述实际行为

```text
请阅读[文件路径/代码片段]，先不要看原需求，也不要修改代码。
用自然语言描述代码实际做了什么，包括输入、分支顺序、边界、返回值、
状态变化和外部副作用。为每个结论附文件路径和行号/符号位置。
区分代码直接显示的事实与依赖缺失导致的未知；不要推测作者本来想做什么。
不要把注释当作实现证据。说明未读到的依赖，避免把函数名当作行为证明。
```

## 第二阶段：与需求比较

```text
原需求：[粘贴已确认需求]
代码反述：[粘贴第一阶段结果]

逐条比较，列出一致、偏离和无法判断的部分，附需求依据及代码位置。
对无法判断的项列出缺失信息与验证动作，不擅自补业务规则。
先给差异及其业务影响，不直接改实现。
```

例如[购物车反例](../code/cart-discount-bug.py)会被反述为“先应用会员折扣，再减30元”，与“满200减30，不能和其他优惠叠加”冲突。该需求尚未决定两种优惠如何二选一，不能把某种选择当作原需求；[本地练习](../code/cart-discount-exercise/README.md)另行给出了“取更优惠者”的明确契约。
