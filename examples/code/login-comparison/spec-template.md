# Spec文档最小模板

> 来源：《驾驭AI编程》第5章 5.5节
> 说明：用8行Spec定义"什么算对、什么算错"，再让AI写代码

## 功能：[功能名称]

### 成功标准
- [输入什么 → 返回什么，格式/内容/有效期等]
- [返回值需要包含哪些字段]

### 失败条件
- [错误输入 → 返回什么状态码，不泄露什么信息]
- [异常行为 → 触发什么保护机制，持续多久]
- [边界输入 → 如何拒绝]

### 边界条件
- [大小写/编码/格式的处理规则]
- [长度/数量的上下限]
- [并发/竞态条件的处理方式]

### 安全要求
- [敏感数据如何存储和传输]
- [频率限制/防滥用策略]
- [日志记录哪些事件（不记录哪些敏感字段）]

---

**示例（用户登录）：**

## 功能：用户登录

### 成功标准
- 正确的邮箱+密码返回JWT token，有效期24小时
- token包含用户ID和角色信息

### 失败条件
- 错误密码返回401，不泄露"用户是否存在"
- 连续5次失败锁定账户15分钟
- 不接受空邮箱或空密码

### 边界条件
- 邮箱不区分大小写
- 密码最少8位，最多128位
- 并发登录：同一账户最多3个活跃session
