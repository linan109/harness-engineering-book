# CIVR快速检查：开始AI编码任务前的10个问题
> CIVR Quick-Check: 10 Questions Before Starting an AI Coding Task | 来源：《驾驭AI编程》第2章 2.3节

把需求扔给AI之前，花30秒过一遍这个清单。简单任务看前三条就够了；重要功能交给AI时，把十条都想一遍，可能省三天的debug时间。

---

### 约束（Constrain）

- [ ] **AI能访问哪些文件和目录？** 不需要的排除掉
- [ ] **工具集精简了吗？** 它真的需要那么多工具吗？
- [ ] **破坏性操作有防护吗？** 删除、覆盖、数据库变更是否需要人工确认？

### 告知（Inform）

- [ ] **项目上下文准备好了吗？** CLAUDE.md或等效文件是否是最新的？
- [ ] **任务目标和成功标准写清楚了吗？** "帮我优化一下"不是目标
- [ ] **信息会不会过载？** 你给的上下文是否超过了完成任务所必需的量？

### 验证（Verify）

- [ ] **怎么确认产出正确？** 有自动化测试还是只靠肉眼？
- [ ] **谁做最终验收？** 你自己还是另一个AI？还是两者都要？

### 校准（Redirect）

- [ ] **出错了走什么流程？** 有没有自动回退机制？
- [ ] **是在修根因还是在堆补丁？** 同一个问题出现第二次，该回去调整约束或告知了

---

**使用建议：** 把这10个问题写进PR模板（提交前强制填），或者写进CLAUDE.md让AI在session开始时自动提醒。最低限度，把前三个问题变成习惯——三秒钟就能回答的那种。
