# 告知检查清单：上下文给到位了吗？
> Inform Checklist: Is Your Context Good Enough? | 来源：《驾驭AI编程》第4章 4.9节

每次给AI布置任务前，用这份清单检查你的上下文质量。上下文给对了不代表AI一定对，但上下文给错了AI一定会猜。

---

### 给什么（对应4.1-4.2）

- [ ] 假装自己是刚入职一周的新人读需求，哪里需要问同事？在那里补信息
- [ ] 有没有"AI不知道就会猜错"的隐含知识？写下来
- [ ] 给了心智模型（系统怎么运转）还是只给了需求？
- [ ] 告诉AI"为什么不"了吗？（被放弃的技术选型、被拒绝的方案）
- [ ] 涉及框架/API时，标注了项目使用的版本吗？

### 怎么给（对应4.3-4.5）

- [ ] 贴了代码/示例，还是只在描述？（Show, Don't Tell）
- [ ] 报错给了三元组吗？（完整错误信息 + 触发操作 + 预期vs实际）
- [ ] 大任务先让AI复述理解了吗？（反转流程）
- [ ] 信息按需分层了吗？（项目概况 / 模块详情 / 完整文档三层）
- [ ] 不确定AI需要什么时，先让它探索了吗？

### 维护（对应4.6）

- [ ] AI出现污染信号了吗？（重复否决方案、张冠李戴、风格漂移）出现两个以上，开新session
- [ ] 重要计划和决策外化到文件了吗？别只存在上下文里
- [ ] CLAUDE.md上次审查是什么时候？超过一个月该扫一遍了
